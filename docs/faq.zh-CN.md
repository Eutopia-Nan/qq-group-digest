# 常见问题：自定义

[English](faq.md) | **简体中文**

以下修改都在项目根目录的 **`config.json`** 里完成（用记事本或 VS Code 打开）。改完建议先试运行一次，确认没有报错，这一步不调用 AI、不花钱：

```bash
python digest.py --preset daily --dry-run
```

> 编辑时注意：只改引号里面的内容；使用英文标点 `"` `,` `:`；列表的最后一项后面不能有逗号；路径写成 `/` 或 `\\`。写错时程序会提示出错的行号。

## Q1：怎么修改要处理的群？

修改 `groups`：

```json
"groups": [
  { "id": 123456789, "name": "我的学习群", "type": "study" },
  { "id": 987654321, "name": "我的技术群", "type": "opensource" }
],
```

| 想做什么 | 怎么改 |
|---|---|
| 新增群 | 照格式加一行，上一行末尾补逗号。`id` 是群号，在导出文件名 `群_<群号>_<群名>.csv` 里能看到；`name` 可以随意写 |
| 不再处理某个群 | 删掉那一行，并确保删完后最后一行后面没有逗号 |
| 只临时处理一个群 | 不用改配置，运行时加参数：`python digest.py --preset daily --group 123456789` |
| 处理一个不在列表里的文件 | `python digest.py --file "文件路径" --type study --hours 24` |

新增的群需要先导出聊天记录，否则会提示"没找到导出文件"。

## Q2：怎么修改群的类型（type）？

修改 `groups` 里每个群的 `"type"`，它决定 AI 用哪一套分类来筛选这个群。

- `type` 只能填 `topics` 里**已经存在的名字**，默认有 `study`（学习群）和 `opensource`（技术/开源群）
- 换成另一种已有类型：直接改值，例如把 `"type": "study"` 改成 `"type": "opensource"`
- 需要新类型：先按 [Q3](#q3怎么修改希望聚焦的信息) 在 `topics` 里新建，再把群的 `type` 改成新名字
- 填了不存在的类型时，程序会在调用 AI **之前**报错，不会产生费用

## Q3：怎么修改希望聚焦的信息？

由三个字段共同决定：

**① `profile`：你是谁、想要什么（影响最大）**
```json
"profile": "计算机专业大二学生，会 Python，想找暑期实习和线上兼职，最近在准备期末高数考试。"
```
写得越具体越准。AI 会据此判断哪些信息对你有用，以及你是否符合某个机会的门槛。

**② `topics`：每类群筛哪些分类**
```json
"study": {
  "label": "学习群",
  "focus": "对提高成绩有帮助的信息",
  "categories": {
    "考试与作业通知": "考试时间/范围、作业截止、老师重点划分、课程调整",
    "学习资料": "真题、课件、笔记、网课、题库链接或文件"
  }
}
```
- `label`：这类群是什么；`focus`：总体最关心什么；`categories`：分类名 → 这个分类收集什么
- 加分类：在 `categories` 里加一行 `"分类名": "收集什么"`；删分类就删掉那一行
- 新建类型：照着 `study` 复制一整块，改个名字（例如 `"class"`），和已有类型并列，中间用逗号隔开
- 不用写"其他有用"分类，程序会自动加上

**③ `explain_style`：要不要解释术语**
```json
"explain_style": "用户是零基础，用通俗大白话 + 生活类比解释清楚（2-4 句）"
```
- 想要简短：改成 `"用户有一定基础，一句话简要说明"`
- 不要解释：改成 `""`，报告里也不会再有术语小词典

## Q4：怎么修改回溯的时间？

| 想要 | 怎么做 |
|---|---|
| 长期修改"今日快报"或"今周快报"的时长 | `presets` 里的 `hours`（单位是小时） |
| 临时看最近 N 小时 | `python digest.py --hours 72`（3 天）、`--hours 720`（30 天） |
| 只看上次运行之后的新消息 | `python digest.py`（不带时间参数），已经处理过的消息不会重复处理 |
| 导出文件里的全部历史 | `python digest.py --all`（消息多时很费钱，慎用） |

```json
"presets": {
  "daily":  { "hours": 24,  "title": "今日快报", "report_dir": "reports/今日快报" },
  "weekly": { "hours": 168, "title": "今周快报", "report_dir": "reports/今周快报" }
}
```

- 新增预设：例如加一项 `"monthly": { "hours": 720, "title": "本月快报", "report_dir": "reports/本月快报" }`，然后运行 `python digest.py --preset monthly`
- **回溯范围不能超过导出文件本身**：想看最近 7 天，要先重新导出，确保文件里有这 7 天的消息
- 使用 `--hours` 或 `--preset` 运行时，不会影响"上次运行到哪"的记录
